## 🛠️ Common Troubleshooting

### 🎤 Voice Not Working
1. Check browser microphone permissions
2. Ensure mic not muted/used by other apps  
3. Refresh page and re-grant permissions
4. Test mic in other applications

### 📧 Google Sync Issues
1. Go to Settings > Integrations
2. Disconnect and reconnect Google account
3. Verify all required permissions granted
4. Wait 15 minutes for sync to complete

### 🤖 AI Task Problems
1. Be more specific in your requests
2. Break complex tasks into smaller parts
3. Use appropriate AI agent for task type
4. Provide more context and examples
