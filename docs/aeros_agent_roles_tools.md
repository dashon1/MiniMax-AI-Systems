## 🎯 Agent Selection Logic

### **Task Routing Algorithm:**
The system automatically suggests the best agent based on:

1. **Task Content Analysis**
   - Keywords and context
   - Complexity assessment
   - Required output type
   - Technical requirements

2. **Agent Specialization Matching**
   - Core competency alignment
   - Tool requirement matching
   - Previous success rates
   - Current availability

3. **User Preferences**
   - Historical agent preferences
   - Success rate with specific agents
   - Current subscription tier
   - Credit availability

### **Multi-Agent Collaboration:**
Some complex tasks may involve multiple agents:
- **MANUS + ABACUS:** Business process optimization with data analysis
- **GENSPARK + MVP:** Creative strategy for startups
- **MINIMAX + ABACUS:** AI-powered analytics solutions
- **MANUS + MVP:** Enterprise innovation strategies

## 💡 Credit Optimization Strategy

### **Task Complexity Factors:**
- **Simple (5-10 credits):** Basic queries, simple analysis
- **Medium (10-15 credits):** Standard processing, content generation
- **Complex (15-25 credits):** Advanced analytics, multi-step processes
- **Expert (20-30 credits):** Specialized technical tasks, complex modeling

### **Credit Efficiency Tips:**
- Combine related tasks into single requests
- Use specific, detailed prompts
- Choose the most appropriate agent for the task
- Leverage Pro tier for unlimited access to complex tasks
